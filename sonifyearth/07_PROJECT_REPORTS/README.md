# 07_PROJECT_REPORTS

This directory stores formal analytical summaries, research notes, and validation audits for the NASA Space Apps Challenge submission.

## Structure
- `research/`: Research notes on LIS instrument physics, optical transient detection, and acoustic translation theory.
- `validation/`: Audit logs, checksum tables, and automated test outputs certifying data fidelity.
- `coverage/`: Orbital coverage maps, latitude coverage breakdowns, and day/night observation ratios.
