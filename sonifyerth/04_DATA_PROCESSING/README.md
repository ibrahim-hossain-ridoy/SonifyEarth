# 04_DATA_PROCESSING

This directory houses the core Python data transformation pipelines that convert raw NASA NetCDF-4/HDF granules into clean scientific structures.

## Structure
- `scripts/`: Python scripts for data ingestion, anomaly filtering (SAA, glints), coordinate reprojection, and normalization.
- `configuration/`: JSON/YAML configuration files specifying geographical bounds, noise filter thresholds, and processing parameters.
